# Языки

Типичные требования по языку. Применяй вместе с профилем рантайма
(bun, rust) — этот файл про сам язык, не про сборку.

## TypeScript / JavaScript

- Строгий режим. Не отключай `strict` ради того, чтобы ошибки исчезли —
  они не исчезают, а прячутся
- `unknown` вместо `any` на границах. `any` — только внутри, где тип известен
- Не дублировать рантайм-типы вручную: `Bun.file` вместо `node:fs`,
  `Bun.serve` вместо `node:http`
- `as` — не проверка. Если нужен `as`, сначала проверь рантаймом
- Не мутируй входные параметры

## Python

- Типы в сигнатурах, не только в докстрингах
- Виртуальное окружение в проекте, не глобально
- Не используй `type: ignore` без причины в комментарии

## Rust

См. профиль `rust.md` — он отдельный, потому что там FFI, panic-границы
и tokio.

## Общее

- Форматирование — инструментом проекта, не руками
- Имена: предметные, не сокращённые до нечитаемости
- Комментарий объясняет «почему». Пересказ кода — не комментарий
- Не оставлять закомментированный код: удалить или объяснить, почему он нужен
